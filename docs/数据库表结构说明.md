# 数据库表结构说明

本文与 **`database/schema_mysql8_full.sql`** 保持一致，字段级注释以 SQL 内 `COMMENT` 为准。以下为表级索引说明。

| 表名 | 说明 |
|------|------|
| `users` | 登录用户 |
| `projects` | 项目 |
| `project_versions` | 项目版本 |
| `requirement_assets` | 需求资产（文本/文档/原型） |
| `prompt_templates` | Prompt 模板 |
| `model_configs` | 大模型连接配置 |
| `generation_tasks` | 用例生成任务 |
| `generation_task_refs` | 任务引用参考版本 |
| `ui_nl_cases` | UI 自然语言用例库 |
| `ui_nl_tasks` | UI 自然语言任务 |
| `ui_nl_task_steps` | UI 自然语言任务步骤 |
| `ui_nl_reports` | UI 自然语言测试报告 |
| `test_cases` | 功能测试用例 |
| `api_test_cases` | 接口测试用例 |
| `test_case_status_logs` | 功能用例执行/评审状态变更日志 |
| `test_case_histories` | 功能用例内容历史快照 |
| `export_records` | 导出任务记录 |
| `operation_logs` | 操作审计日志 |

## 通用约定

- **`is_deleted`**：`0` 未删除，`1` 已删除（逻辑删除）。`operation_logs` **无** 此字段。
- **`created_by` / `updated_by`**：操作人用户 ID（当前实现中常见固定为 `1`）。
- **时间字段**：`DATETIME`，应用层时区见 Spring/JDBC 配置（如 `Asia/Shanghai`）。
- **JSON 类型列**：MySQL `JSON`；Java 实体中部分以 `String` 映射，由 MyBatis 序列化。

## 业务编码习惯（非数据库约束）

- 资产：`asset_code` 唯一；`relation_code` 标识同一批/同一需求组。
- 用例：`case_no` 唯一（功能 `TC-...`、接口 `ATC-...` 等由服务生成）。
- 导出：`export_no` 唯一（如 `EXP-...`）；前端列表列名「编码」对应该字段。
- 任务：`task_no` 唯一。
- UI 自然语言用例：`case_no` 唯一（`NLC-...`）。
- UI 自然语言任务：`task_no` 唯一（`UIT-...`）。
- UI 测试报告：`report_no` 唯一（`REP-...`）。

## 与前端展示差异

- **`export_records.export_content`**：不存在于表中；列表「导出内容」由后端从 `request_json` 等解析后填入 DTO。
- **项目 `owner` / `archived`**：以 API 聚合结果为准，库表以 `owner_user_id`、`is_deleted` 等为主。
