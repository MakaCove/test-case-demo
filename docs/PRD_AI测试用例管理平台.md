# AI 测试用例管理平台 — 产品说明（与当前代码对齐）

**版本说明**：本文档依据仓库当前前后端实现整理，用于描述「已具备能力」与「已知简化点」，便于交付与二次开发。

---

## 1. 产品定位

面向测试与研发团队的 **需求资产 → AI 生成任务 → 功能/接口测试用例 → 评审与执行 → 导出** 的一体化工作台，配套 **模型配置、Prompt 模板、操作日志** 等基础能力。

---

## 2. 角色与认证

- 支持 **登录 / 退出**；令牌存储于前端 `localStorage`。
- 后端对资源操作在多处使用固定操作人 ID（如 `1L`）写入审计字段，**多租户/细粒度权限为后续扩展点**。

---

## 3. 功能模块（已实现）

### 3.1 看板

- 汇总：项目、版本、需求资产、功能用例、接口用例数量；待评审/未执行统计；生成任务排队与运行概况；导出排队/进行中；最近导出列表；最近操作日志。
- 支持手动刷新；活动任务列表定时轮询。

### 3.2 项目管理

- 项目的增删改查、分页列表；支持按 **名称、编码** 筛选；批量删除（归档式逻辑删除）。
- API 返回的 `owner`、`archived` 与库表字段为 **展示层映射**（如负责人展示名、归档与 `is_deleted` 等），以实际后端 `ProjectController` 为准。

### 3.3 版本管理

- 按项目维护版本；列表、详情、更新、删除、发布；支持跨项目 **版本列表** 查询（用于资产等筛选）；版本对比接口为 **占位文案**（MVP）。

### 3.4 需求资产

- 支持 **TEXT / FILE / PROTOTYPE** 三类资产；文本创建、文件/原型上传。
- 列表按 **关联批次码 `relationCode`** 聚合展示（同批多条合并一行）；支持 **单条删除、批量删除**（按 relationCode）；详情页按关联查询。
- 列表展示 **ID、资产编码（`assetCode`）、关联批次码、标题、三类有无、更新时间** 等。

### 3.5 生成任务

- 提交异步任务：选择项目、版本、模型配置、Prompt、用例类型（**功能 / 接口**）、策略与条数等。
- 任务状态：**排队、运行中、完成、失败、取消**；支持中断、重试、启动、取消、编辑（受状态约束）、**单条删除、批量删除**。
- 结果可 **物化成功能用例**（接口路径见接口清单）。

### 3.6 功能测试用例

- 列表筛选：项目、版本、标题关键字、评审状态、执行状态、优先级（下拉）；支持新增、编辑、删除、批量删除、批量评审、批量执行。
- **单条评审 / 执行** 弹窗与列表、详情页一致；详情含 **状态日志、历史快照**。
- 关键字检索仅匹配 **标题**（与后端一致）。

### 3.7 接口测试用例

- 列表与详情维护 **request/expected/assertions** JSON 文本；筛选与交互与功能用例侧 **评审/执行** 体验对齐。
- 关键字检索仅匹配 **标题**。

### 3.8 模型配置 & Prompt 模板

- 模型：增删改查、启用/禁用、连通性测试（依赖后端实现）。
- Prompt：全局/项目作用域、版本号、启用禁用；内容为大段文本。

### 3.9 导出中心

- 创建导出任务（如 Markdown）；列表展示状态、**编码（`exportNo`）**、导出内容说明（多由 `request_json` 解析）、下载、失败重试。
- **数据库无单独 `export_content` 列**，展示字段由服务层组装。

### 3.10 操作日志

- 分页查询；记录对象类型、对象 ID、动作、前后 JSON、操作人、备注等。

## 4. 非目标 / 已知简化

- **覆盖率报告**：历史脚本中曾出现 `coverage_reports` 表，**当前 Java 实体与业务未接入**，正式 DDL 已不包含该表。
- **版本对比**：接口返回占位字符串，无真实 diff。
- **权限**：无 RBAC 细粒度控制；操作人多为固定 ID。
- **接口用例**：无与功能用例同级的「状态变更日志表」；执行备注未单独落库，与功能用例状态日志不同。

---

## 5. 技术栈摘要

- **后端**：Spring Boot、MyBatis-Plus、MySQL 8。
- **前端**：Vue 3、Vue Router、Element Plus、Axios；接口前缀 `http://localhost:8080/api/v1`（以本地配置为准）。
