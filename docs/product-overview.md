# 产品说明（与当前代码对齐）

本文描述仓库 **已实现** 的能力与已知简化点，便于交付与二次开发。

---

## 1. 定位

面向测试与研发的 **需求资产 → AI 生成任务 → 功能/接口测试用例 → 评审与执行 → 导出** 工作台，并包含 **模型配置、Prompt 模板、操作日志**，以及 **UI 自然语言用例 → 规划步骤 → 浏览器执行（ui-runner）→ 报告** 链路。

---

## 2. 认证与权限

- 登录后前端使用 **Bearer Token**（`localStorage`）；后端对 `/api/**` 除登录、登出外做拦截校验。
- 审计字段 `created_by` / `updated_by` 在部分路径为固定用户 ID（如 `1L`）；**细粒度 RBAC 为后续扩展**。

---

## 3. 功能模块（已实现）

| 模块 | 能力摘要 |
|------|----------|
| **看板** | 项目/版本/资产/用例统计；生成任务与导出概况；近期操作与入口 |
| **项目 / 版本** | CRUD、分页筛选；版本发布；跨项目版本列表；版本对比接口为占位 |
| **需求资产** | TEXT / FILE / PROTOTYPE；上传与列表；`relationCode` 批次；批量删除 |
| **生成任务** | 选择模型、Prompt、用例类型（功能/接口）、参考版本等；排队/运行/完成/失败/取消；中断、重试、启动；物化到用例库 |
| **功能用例** | 列表筛选、详情、增删改、批量操作、单条评审/执行状态；状态日志与历史快照 |
| **接口用例** | 列表筛选、JSON 字段维护；评审/执行与功能用例体验对齐 |
| **模型配置 / Prompt** | CRUD、启用禁用；模型连通性测试 |
| **导出中心** | 创建导出任务、下载、失败重试；展示字段部分由 `request_json` 解析 |
| **操作日志** | 对象类型、动作、前后快照、操作人 |
| **UI 自然语言** | 用例库、任务中心、步骤管理、任务步骤详情（规划步骤与执行轨迹）、测试报告与 HTML 报告；规划步骤的 LLM 提示词见 [`docs/prompts/UI自然语言_规划步骤_LLM提示词.md`](./prompts/UI自然语言_规划步骤_LLM提示词.md) |

---

## 4. UI 自然语言（简要）

- **规划状态**（`ui_nl_tasks.status`）：如 PENDING → QUEUED → PLANNING → READY（及失败/中断/取消等）——表示 **步骤生成** 流程。
- **执行状态**（`last_exec_status`）：RUNNING / COMPLETED / FAILED / CANCELLED 等——表示 **最近一轮浏览器执行**。
- 浏览器真实执行由独立服务 **ui-runner**（FastAPI + browser-use）完成，Java 后端通过 HTTP 提交与轮询；详见 `ui-runner/README.md` 与 `docs/architecture.md`。

---

## 5. 非目标 / 已知简化

- **版本对比**：接口为占位，无真实 diff。
- **权限**：无多租户与资源级授权。
- **接口用例**：无与功能用例同级的「状态变更日志表」；执行轨迹以功能用例侧为主。
- 状态枚举以 **`StatusConstants`（后端）与 `statusDictionary`（前端）** 为准，库表注释见 `schema_mysql8_full.sql`。
